# 2026-09-12

## Instore listing removal support prepared

- The customer feed and checkout resolver now reject only SKUs explicitly marked hidden by the separate Instore listing-control read model. Image-only hiding remains presentation-only and does not affect sale eligibility.
- This code depends on admin migration `069_instore_listing_controls.sql`, which is now applied. No production SKU has been hidden or changed.

## Instore image-only safety controls (preview branch)

- The Instore feed can now honour a private image-control record: a misleading image is replaced by an “Image being updated” placeholder while the approved SKU, current price, stock threshold, duplicate gate, and checkout eligibility remain intact.
- Checkout no longer treats the presence of a remote image URL as an ordering requirement; all product, duplicate, review and live-stock checks remain required.
- Deployment: not deployed. The companion admin migration has not been applied to the production stock database.
